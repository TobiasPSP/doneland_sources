# BatCharger 1.6.3

Confirmation buttons, including the numeric/WiFi keyboard checkmark, use the
original softer green `#89e5ad` to match the pastel button palette. SOC progress
keeps the saturated `#00ff35` fill. Native and web styles now use separate color
constants for buttons and SOC progress. Exported SOC bars stay saturated too.

Only presentation colors and the diagnostic version change. Native preview,
web regression and ESP32-S3 build validated. No hardware flashed.
