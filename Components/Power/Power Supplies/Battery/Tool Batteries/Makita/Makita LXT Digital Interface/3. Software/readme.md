# Software for Makita Dongles

> Sending Commands to Makita Batteries, and Getting Results back

Most firmwares based on the *OpenBatteryInformation* project are just *dongles* and emulate the 1-Wire Makita protocol only. To use them, you need separate software that runs on a PC.


* The original *ArduinoOBI* dongle ships with *OpenBatteryInformation*, a graphical user interface based on a Python script.
* You can use any script language you want to talk to Makita batteries. To better understand how Makita dongles work, there is also a PowerShell script that can be easily tweaked.
