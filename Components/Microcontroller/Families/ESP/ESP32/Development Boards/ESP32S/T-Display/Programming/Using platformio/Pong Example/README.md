# Pong Example

> Uploading a Pong Sketch to T-Display


[Downloading](materials/t_display_pong.zip) a *known-good* project targeting T-Display can serve as a test tool to verify that your board is working fine. This [Zip file](materials/t_display_pong.zip) contains the ready-to-go *platformio project* for a *Pong Example*.

## Prepare Source Code
After downloading the [Zip file](materials/t_display_pong.zip), *unblock* and *unzip* the file, then open the unzipped folder in *VSCode*.   

Connect your T-Display board via USB cable to your PC. Next, in VSCode, switch to the *platformio extension* (click the "Alien head" in the left vertical panel), then click *Upload* - done.
